パソコンを目覚ましにする方法

公開日：2026年11月19日

在宅の日や、パソコンのそばで寝る方なら、パソコンのブラウザでも推しの YouTube を目覚ましにできます。確実に鳴らすための3つのポイントを解説します。

3つのポイント
  1. アプリのページ（タブ）を開いたままにする
  2. このサイトのポップアップを許可する
  3. パソコンがスリープしないようにする

1ページを開いたままにする

推しと共に目覚ましアラーム(仮)は、Chrome・Edge・Safari などのブラウザでそのまま使えます。インストールは必要ありません。

パソコンでは、このタブを開いたままにしておけば、ほかのタブやアプリで作業していても鳴ります。タブを閉じたり、ブラウザを終了したりすると鳴りません。

時刻になった時の動き方は、⚙設定のPCでの起動方法で選べます。

設定動き方
自動（おすすめ）このタブを表示している時はページの中で再生、別のタブを表示している時は YouTube を新しいタブで開く
常にこのページ内で再生いつもページの中で再生します。アプリの音量設定が効きます
常に YouTube を新しいタブで開くいつも新しいタブで開きます。アプリの音量設定は効きません

寝る前は、アプリの🌙画面(本ウィンドウのみ)を暗くするを押すと、このウィンドウが暗い時計の表示になり、画面が消えないようブラウザにお願いした状態で待機します（ブラウザによっては、この機能に対応していないことがあります）。

2ポップアップを許可する

別のタブを見ている時に YouTube を新しいタブで開くには、ブラウザでこのサイトのポップアップを許可しておく必要があります。許可していないと、時刻になってもブラウザに新しいタブを止められてしまいます。その時はアラーム音で知らせ、アプリのタブに戻ると再生します。

Chrome の場合

設定 → プライバシーとセキュリティ → サイトの設定 → ポップアップとリダイレクト で、このサイトを「許可」に追加します。ポップアップが止められた時にアドレスバーの右側に出るアイコンから許可することもできます。

Edge の場合

設定 → Cookie とサイトのアクセス許可 → ポップアップとリダイレクト で、このサイトを「許可」に追加します。

Safari（Mac）の場合

Safari → 設定 → Webサイト → ポップアップウインドウ で、このサイトを「許可」にします。

※ ブラウザのバージョンにより、メニューの名前や場所が異なる場合があります。

あわせて、⚙設定のデスクトップ通知を許可するを押しておくと、別のタブで作業中に時刻になった時、通知でも知らせます。

3スリープしないようにする

パソコンがスリープに入ると、ブラウザも止まるので鳴りません。寝る前に、電源の設定を確認しておきましょう。

Windows 11

設定 → システム → 電源とバッテリー（または電源）→ 画面とスリープ で、電源に接続時にスリープ状態にする時間を「なし」または起きる時刻までより長い時間にします。

Windows 10

設定 → システム → 電源とスリープ で、同じように「スリープ」の時間を変更します。

Mac

システム設定 のディスプレイやバッテリー（デスクトップの Mac では省エネルギー）の中に、ディスプレイがオフの時に自動でスリープさせないための項目があります。

※ Windows・macOS のバージョンや機種により、表示が異なる場合があります。

ノートパソコンの注意
  • ふたを閉じるとスリープするのがふつうです。ふたは開けたままにしてください。
  • 電源につないでおきましょう。バッテリーだけだと、残りが少なくなった時にスリープすることがあります。

4タブの省電力機能とアップデートにも注意

  • 使っていないタブを休ませる機能：Chrome の「メモリセーバー」や Edge の「スリープ中のタブ」など、しばらく見ていないタブを止めてメモリを節約する機能があります。設定画面（Chrome は設定 → パフォーマンス、Edge は設定 → システムとパフォーマンス）で、このサイトを「常にアクティブにする」などの例外に追加しておくと安心です。
  • 夜中の自動アップデート：Windows の更新による再起動が夜中に行われると、ブラウザも閉じてしまいます。設定 → Windows Update の詳細オプションにある「アクティブ時間」を、寝ている時間を含むように設定しておくと、再起動を避けやすくなります。

5寝る前のテスト

  1. アラームの一覧からアラームを開き、▶ テスト再生で音の大きさを確かめる
  2. 数分後の時刻でアラームを1つ作り、別のタブに切り替えて待ってみる
  3. 時刻に YouTube が新しいタブで開けば、ポップアップの設定はOK（⚙設定の「PCでの起動方法」が「自動」または「常に YouTube を新しいタブで開く」の時）

うまく音が出ない時は「YouTube の音が出ない時に確認すること」をご覧ください。パソコンとあわせて、スマホを枕元に置いて使う方は「朝を気持ちよく始めるアイテム」のスタンド・ケーブルも参考にしてください。

あわせて読みたい

  • YouTubeの音が出ない時に確認すること｜iPhone・パソコン別チェックリスト朝のアラームで YouTube の音が出なかった時の確認ポイント。自動再生の制限、本体の音量、消音スイッチ、Bluetooth の出力先、アプリ内の対処を順番に見ていきます。
  • 画面ロック中にWebのアラームは鳴る？ブラウザの仕組みと対策iPhone の画面をロックするとブラウザのアラームはどうなるのか。仕組みと、実験的な「画面ロック中も、アラーム音で起こす」設定の使い方・注意点を解説します。
  • 推しの朝配信を見逃さないコツ｜配信予定の確認とアラームの使い分け朝配信で起きたい人向けに、配信予定の確かめ方と、「最新のライブ配信」「最新の動画」「決まった動画」の使い分け、時刻の決め方をまとめました。
  • 配信を見ながらできる朝の1分ストレッチ｜布団の上でもOK・無理せず安全に推しの配信を流しながら、布団の上やその場でできるかんたんな朝のストレッチを紹介します。反動をつけない、痛い時はやめるなど、安全に行うための注意点もまとめました。
  • 使い方ガイドの一覧を見る寝る前の準備から、困った時の対処まで

明日の朝は、推しの配信で起きてみよう。

無料・会員登録なし。ブラウザで開いて、時刻とチャンネルを選ぶだけです。
