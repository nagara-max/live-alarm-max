# Live目覚まし（個人利用版）

指定した時刻に、指定した YouTube チャンネルの**最新のライブ配信**を再生する Web アプリです。
配信中のライブがあればそれを、なければ直近の配信済みアーカイブを再生します。配信予定（upcoming）の枠は再生しません。

- サーバー不要の静的サイト（HTML 1枚）。費用は 0 円
- 設定・APIキーはすべて**その端末のブラウザ内**（localStorage）に保存

## ファイル構成

```
index.html              アプリ本体
config.js               公開設定（backendUrl を入れると公開モード）
privacy.html            プライバシーポリシー・利用規約
manifest.webmanifest    ホーム画面追加用
icons/                  アイコン
Macで起動.command        PC（Mac）で手元から開く
Windowsで起動.bat        PC（Windows）で手元から開く
```

> 他の人にも公開する場合は `03_資料/公開手順.md` を参照してください（利用者は APIキー不要になります）。
> 設定をすべて消したい時は ⚙設定 →「データの管理」→「すべての設定を削除する」。

## 1. YouTube Data API キーを取得（無料）

アプリ内の「APIキーの取り方」ボタン（アラーム追加画面・設定画面の右上）から、同じ手順を重ねて表示できます。

1. https://console.cloud.google.com/projectcreate でプロジェクトを作成
2. https://console.cloud.google.com/apis/library/youtube.googleapis.com で **YouTube Data API v3** を「有効にする」
3. https://console.cloud.google.com/apis/credentials →「認証情報を作成」→「APIキー」
   - アプリケーションの制限: **ウェブサイト** → `https://<ユーザー名>.github.io/*`（PCで試すなら `http://localhost:8000/*` も）
   - API の制限: YouTube Data API v3
   - サービスアカウントに関するチェックはオンにしない
4. アプリのキー欄に貼り付けて「確認して保存」

支払い情報の登録は不要です。無料枠は 1 日 10,000 ユニット、1 回の確認に使うのは約 3 ユニットです。

### うまくいかない時
エラーが出ると、アプリが原因と直し方を表示します。多いのは次の4つです。
- 作った直後：反映まで最大5分ほど待つ
- 「API が有効になっていません」：キーを作ったのとは別のプロジェクトで有効にしている（Googleアカウントの切り替えに注意）
- 「URLが許可されていません」：ウェブサイトの制限に、アプリに表示されたURLを登録する
- ファイルを直接開いている、またはプレビュー画面の中で開いている：公開したURLをブラウザで直接開く

### Googleアカウントが2つある場合
どちらのアカウントで作ってもかまいません。YouTube にログインしているアカウントとは関係ありません。手順1〜3を**同じアカウント・同じプロジェクト**で行ってください。

## 2. 公開する（iPhone で使うには HTTPS の URL が必要）

### GitHub Pages（無料）
1. GitHub で新しいリポジトリ（例: `live-alarm`）を作成（Public）
2. このフォルダの中身をアップロード（「Add file」→「Upload files」）
3. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/live-alarm/` で開けます

### PC だけで試す場合
```
cd live-alarm
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開きます。`file://` で直接開くと YouTube の埋め込み再生が動きません。

## 3. 使い方

- **PC**: ページを開いたままにしておきます。別のタブを見ている時は YouTube を新しいタブで開くので、そのサイトの**ポップアップを許可**してください。
- **iPhone**: Safari で開く →「共有」→「ホーム画面に追加」→ ホーム画面のアイコンから起動します。寝る前に充電しながら「おやすみモード」を開始してください。初回だけ ▶ をタップする再生テストがあります。
- **2分後にテスト**（おやすみモード画面の下）で、必ず一度動作を確認してください。

## 仕様と制限

| 項目 | PC | iPhone（Safari） |
|---|---|---|
| 曜日設定（平日（土日祝除く）／月〜金／毎日／曜日ごと） | ○ | ○ |
| 音量設定 | ○（ページ内で再生する時のみ） | アラーム音のみ。YouTube の音量は本体ボタンで調整 |
| マナーモード（消音スイッチ）中 | ― | 鳴る（本体の音量が 0 の時は鳴らない） |
| 画面ロック中 | ― | YouTube は再生できない。「ロック中モード（実験的）」ならアラーム音を鳴らし、ロック解除後に YouTube を再生 |
| 祝日判定 | holidays-jp API を使い、取得できない時は法律の規則から計算 | 同左 |

## 動作確認チェックリスト

- [ ] PC: ページ内で再生され、音量設定が反映される
- [ ] PC: 別のタブを表示中に、YouTube が新しいタブで開く（ポップアップ許可後）
- [ ] iPhone: ホーム画面から起動し、おやすみモードの再生テストで音が出る
- [ ] iPhone: 画面を点けたまま「2分後にテスト」で自動再生される
- [ ] iPhone: マナーモードのスイッチをオンにしても鳴る
- [ ] iPhone: ロック中モードで、画面ロック中にアラーム音が鳴る
