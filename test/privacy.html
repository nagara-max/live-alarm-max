1. YouTube API サービスの利用について

本サービス「推しと共に目覚ましアラーム(仮)」（旧名称：Live目覚まし。以下「本サービス」）は、YouTube の配信情報の取得と再生に YouTube API サービスを利用しています。本サービスを利用することで、YouTube 利用規約に同意したものとみなされます。YouTube（Google）による情報の取扱いについては Google プライバシーポリシーをご確認ください。

2. 端末に保存する情報

本サービスは、ブラウザの保存領域（localStorage・Cookie）に次の情報を保存します。これらはお使いの端末の中だけにあり、運営者には送信されません（下記3の統計を除く）。

  • アラームの設定（時刻・曜日・チャンネル・音量など）
  • 各種設定、使い方の表示履歴
  • 統計用のランダムな識別子（ブラウザごとに自動生成。個人を特定する情報を含みません）。同じ端末の Safari とホーム画面アプリを1台として数えるため、Cookie にも保存します（広告や他サイトでの追跡には使いません）
  • （iPhone の Safari のみ）アラーム設定の写し。「ホーム画面に追加」した時に、ホーム画面版へ設定を引き継ぐために Cookie に保存します（運営者には送信されません）
  • （個人モードのみ）利用者が登録した YouTube Data API キー

⚙設定の「すべての設定を削除する」で、いつでもすべて削除できます。

3. 送信する情報（匿名の利用統計）

サービス改善のため、次の情報を運営者のサーバー（Google Apps Script）に送信し、運営者の Google ドライブ上のスプレッドシートに記録します。⚙設定の「匿名の利用統計を送信」をオフにすると送信を停止します。

送信する情報例
ランダムな識別子・セッション識別子ブラウザごと／起動ごとの無作為な文字列
操作の記録と日時画面を開いた、アラームを保存した、アラームが鳴った、再生が始まった など
選択したチャンネル・再生した配信チャンネルID・チャンネル名、動画ID・タイトル
設定の傾向アラームの時台、曜日設定の種類、音量
エラーの内容エラーの種類・コード
端末の種類PC／iPhone、ブラウザの種類、ホーム画面から起動したか、アプリの版、言語設定、タイムゾーン（例：Asia/Tokyo）
紹介ページ（HP）の閲覧ページを開いた、どこまで読んだか、どのボタンを押したか、ページにいた時間
どこから来たかリンク元のサイト名（ドメインのみ）、URL に付いた紹介元の目印（utm_source など）
設定中のアラーム1日1回、オンになっているアラームのチャンネル・種類・時台

氏名・メールアドレス・位置情報・入力した文字そのもの（URLなど）・IPアドレスは記録しません。

利用目的：どの画面で操作が止まっているかの把握、不具合の発見、よく使われるチャンネルや時刻の傾向の把握による機能改善。また、個人や端末を特定できない形に集計した統計（例：チャンネル別の利用者数、起床時刻の分布）を、本サービスの紹介や、配信者・企業への説明・提案に使うことがあります。

保存期間：記録は最長400日で削除します。YouTube から取得したチャンネル名・動画タイトルは30日で削除し、IDのみを残します。

4. 外部サービスへの送信

送信先内容・目的
YouTube（Google）埋め込みプレーヤーでの再生。YouTube がクッキー等を使用する場合があります
Google Apps Script（運営者のサーバー）配信情報の問い合わせの中継、上記3の統計の受信

法令に基づく場合を除き、ブラウザごとの記録を第三者に提供・販売することはありません（第三者に示すのは、上記の集計した統計だけです）。現在、本サービスに広告はありません。

5. 利用規約

  • 本サービスは無料で提供しています。アラームが確実に鳴ること・配信が再生されることは保証しません。寝坊が許されない予定には、端末標準の目覚まし等を併用してください。
  • 配信の内容は各配信者・YouTube に帰属します。本サービスは YouTube 公式の埋め込みプレーヤーで再生し、映像や音声を加工・保存しません。
  • 本サービスを不正に利用する行為（サーバーへの過度なアクセス等）を禁止します。
  • 本サービスの内容は予告なく変更・終了することがあります。
